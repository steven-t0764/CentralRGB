# Review of the one-click updater (PR #18)

Reviewed on 2026-11-20 against `main` at `a9b89bd` (the updater merged in `b3e3181`). Tests ran under Xvfb with
Python 3.12, CustomTkinter and Pillow. GitHub was replaced by `tests/fake_github.py` (no network).

## Verdict

**Safe to rely on, with one small fix (PR #20) and one note about the PR text.** All the safety properties hold.
I found one error-handling gap: a dropped connection while the checksum list was being read left the update notice
stuck on "Downloading...". The app didn't crash and nothing was installed. PR #20 fixes it and adds a regression
test. PR #18's description ends with a "Generated by Claude Code" footer, which `CLAUDE.md` doesn't allow in PR
descriptions. The commit itself is clean.

## Notes (not fixed, low risk)

- If the app takes longer than 120 s to close, the helper starts setup anyway, and `/CLOSEAPPLICATIONS` can then
  close the app without its normal shutdown. Normal closes take a few seconds, so this is unlikely.
- On Home, the notice card sits over the right end of the "Game overlay" row until **Later** or **Update now** is
  pressed. It is a dismissable notice, so I left it as it is.
- The verified installer waits in `%TEMP%\CentralRGB-update` for the few seconds before setup runs. Another
  program running as the same user could swap it in that window. That program would already be able to run code as
  the user, so this doesn't add a new risk.
- Not verified here (needs a real Windows PC and a release that has `SHA256SUMS.txt`): the silent install, the
  portable exe swap and the relaunch.
